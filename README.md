# NewJeans Game 🐰

A little browser game inspired by NewJeans.

Play as a bunny on roller skates, collect cookies, find the members and unlock photocards along the way.

## About

A pixel-art game featuring all five NewJeans members, 25 collectible photocards, hidden surprises and a Secret Room with its own minigame.

Your progress and photocard collection are saved locally in your browser.

## Controls

### Desktop

- **Move:** Arrow keys or A / D
- **Jump:** Space, W, or Up
- **Interact:** E, S, or Down
- **Pause:** Esc or P
- **Music:** M

### Mobile

Play in landscape mode using the on-screen controls.
